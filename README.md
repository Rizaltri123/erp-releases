# ERP — Rilis

Paket installer ERP untuk server Linux (x86_64). Kode sumber tidak ada di repo ini.

## Instal / update

```bash
curl -fsSL https://github.com/Rizaltri123/erp-releases/releases/latest/download/get-erp.sh | sudo bash
```

Versi tertentu:

```bash
curl -fsSL https://github.com/Rizaltri123/erp-releases/releases/latest/download/get-erp.sh | sudo ERP_VERSION=0.10.0 bash
```

Daftar versi dan catatan perubahan: lihat [Releases](https://github.com/Rizaltri123/erp-releases/releases).
Aplikasi membutuhkan license yang valid; hubungi vendor untuk aktivasi.
